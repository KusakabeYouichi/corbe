# corbé タブの位置ごとの部首プルダウンと、部首でない部品の読み替え

## 要求事項(ユーザー原文の要旨。4 回に分けて届いた)

1. corbé タブで [へん][たれ] などを選んだら、右は自由入力ではなく、それに沿ったものを選ぶプルダウンにする。[指定なし] のときだけテキストボックス。[指定なし] は [texte libre] と書く
2. 位置のプルダウンの、文字の右の余白も押せるようにする(テキストボックスの前まで)
3. [偏][旁] の左に、位置が分かるアイコンを置く(écritu にある)
4. texte libre にはアイコンを付けず左から書く。部首の一覧では字形と名前の間を広げる。プレースホルダーは「élément (ex. 木)」。画数は区切り線の右端に書き、区切り線は項目の間に高さなしで引く
5. 部首ではない構成部品(ユーザーが貼った AI 回答の 23 種類)でも、texte libre で探せるようにする

不具合の報告: 右のテキストに入力があると左のプルダウンが選べない(実機)。のちに「今は直っているようです」

## 対応スコープ

- 対象: corbé タブの行(位置プルダウン・部首の一覧・自由入力)、位置ごとの選択肢の組み立て、入力の読み替え表、索引の再生成(⺈ を寄せない)
- 対象外: 位置付きで部首以外の部品を指すこと(texte libre で入れれば位置を問わず探せる)

## 主要な実装の詳細

### 位置ごとの部首の一覧

- 選択肢は bushu.plist でその位置に分類された字形。**同じ位置・同じ部首番号は 1 項目にまとめる**(「辶 辵 しんにょう」「⺗ 心 したごころ・こころ」)。
  まとめないと、選んでも結果が同じ項目や包含関係の項目が並ぶため(反証役の指摘)
- 照合はその部首の代表字(異体にも当たる)。部首 130(にくづき)だけは 月 で照合する。IDS の日本の字形は にくづき を 月 と書くため、⺼ のままだと 肝 肥 が出ない
- 選んでも 1 字も当たらない項目は出さない(位置ごとの部品の集合と照合候補の交差で判定)。項目数: 偏 89 / 旁 53 / 冠 37 / 脚 60 / 垂 8 / 繞 3 / 構 10
- SwiftUI の Menu は見出しの高さ・位置を変えられないので、**popover の自前の一覧**にした。字形の列幅を固定し、画数の区切りは高さ 0 の線で、右端に画数を重ねる
- 位置を変えると、その行の値は 1 回の代入で空に戻る(古い値で一瞬検索しない)。索引の読み込み前は部首の一覧を押せない

### 押せる範囲

- 位置プルダウン: 外して試すと、Menu は自分の枠全体で反応していた。追加していた contentShape は効いていなかったので外した。UI テスト G6 は、文字の右端と部首ボタンの左端の間の 2 点を押し、メニューが開くかを、メニューにしか無い項目「構」で見る。
  当初の G6 は、行ラベルと同じ名前の項目で判定していて、常に緑になっていた。これは、変異で赤にならなかったことから見つけて直した
- 部首ボタン: contentShape が必要(外すと G6b が赤)

### 部首でない部品(読み替え表)

- AI 回答の 23 種類を実データで確かめた。漢字の部品 17 個は、もともと texte libre で大半が当たる。
  外れの多くは回答の誤りだった(網 = 糹罔、追 = 辶𠂤、康 = 广隶、伝・転 = 云、博・薄 = 尃)
- 片仮名の形と 尚 は、IDS では別の字で書かれているため、読み替え表 `tools/component_input_aliases.tsv` を足した。
  マ → 龴、ナ → 𠂇、ツ → 𭕄、ク → ⺈ 𠂊、尚 → 尚 𫩠 龸。読み替えの中は OR、同じ行の他の文字とは AND。ひらがなは読みと紛れるので受けない
- ⺈ をビルド時と入力時の寄せ(→刀)から外した。⺍(ツ の形)はビルド時の寄せからは外したが、IDS に 1 回も現れないため、入力した ⺍ は従来どおり 小 として照合する(ツ の読み替え先にも入れない)。外さないと ク で 負 争 急 が出ない。結果、[冠 刀] は 負 に当たらなくなった(負 の上は ク の形なので、正しい方向)
- 探せないもの(README に記載): クリ(慶 鹿 の上部は IDS で未符号化)、専(統合漢字の中で部品として現れない)、朗 の左の 良(分解されない)

### 意図した逸脱

- 部首の一覧の、同じ画数の字形の並びはコードポイント順(設計の例「⺗ 心」に合わせた)
- 位置メニューの項目アイコンは ImageRenderer で画像にして出す。描けなかったときは SF Symbol の square を出す(API の都合)

## 残課題 / 申し送り

- 「入力があるとプルダウンが選べない」(実機 iPhone 15)は、シミュレータでは今回の版でも元の版でも再現しなかった。ユーザーからは「今は直っているようです」。原因は不明。G8a/G8b を見張りとして残した
- 脚 の 肉 も 月 で照合するので、脚に 肉 そのものを持つ 9 字(胬 臠 など)は出ない
- 位置付きの行では、部首以外の部品(例 旁 胡)を指定できない(texte libre なら位置を問わず探せる)
