corbé

corbé サポート

corbé(コルベ)は、漢字を 1 字探してクリップボードにコピーする iPhone 用のアプリです。対象は CJK 統合漢字の 20,992 字です。

使い方

  1. 上のタブで探し方を選びます(élément / corbé・Kangxi、Lecture / chinoise・japonaise)。
  2. corbé では、位置(偏・旁 など)と部首を選ぶか、texte libre に部品(木 氵 など)を入れます。chinoise / japonaise では、読みの先頭をかなで入れます。
  3. 出てきた字をタップするとコピーされます。長押しすると、読み・区点・常用/教育/人名用の区分・JLPT の級などが出ます。

よくある質問

キーボードを閉じたい
キーボードの上の「完了」を押すか、結果の空いた所をタップするか、結果をスクロールしてください。
部品を入れても字が出ません
部首の形(木 日 寸 など)はそれ以上分けません。そのため、偏 に 人 を指定しても 村 は出ません。にくづき は 月 として探します。
読みで出ない字があります
読みのデータ(Unicode の Unihan)を持つ字だけが、読みで探せます。部首や部品から探してください。

プライバシーポリシー

Assistance corbé

corbé est une app pour iPhone qui permet de trouver un kanji et de le copier dans le presse-papiers. Elle couvre les 20 992 idéogrammes unifiés CJK.

Utilisation

  1. Choisissez un mode de recherche dans les onglets (élément / corbé ou Kangxi, Lecture / chinoise ou japonaise).
  2. Dans corbé, choisissez une position (gauche, droite…) et une clé, ou saisissez un composant (木, 氵…) en texte libre. Dans chinoise / japonaise, saisissez le début de la lecture en kana.
  3. Touchez un kanji pour le copier. Un appui long affiche les lectures, le code ku-ten, les statuts jōyō, kyōiku et jinmeiyō, le niveau JLPT, etc.

Questions fréquentes

Fermer le clavier
Touchez « 完了 » au-dessus du clavier, touchez une zone vide des résultats ou faites défiler les résultats.
Un composant ne donne aucun résultat
Les formes de clés (木, 日, 寸…) ne sont pas décomposées davantage. La clé de la chair (にくづき) est recherchée comme 月.
Certains kanji n’apparaissent pas par lecture
Seuls les kanji dont la lecture figure dans la base Unihan d’Unicode sont trouvés par lecture. Cherchez-les par clé ou par composant.
